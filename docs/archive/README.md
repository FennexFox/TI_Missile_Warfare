# Archive

Use this directory for superseded durable documentation that is worth retaining
only for historical context.

## Lifecycle

- Prefer deleting obsolete notes when they no longer carry useful context.
- Archive only docs whose old wording may help explain a later decision,
  migration, or rollback.
- Add a short note at the top of archived files explaining what superseded them.
- Do not treat archived files as current guidance.
- Do not move temporary `dev-docs/plan/**` files here just to preserve history.

Current guidance should live in `docs/agent/`, `docs/guide/`, `docs/planning/`,
`docs/diagnostics/`, `docs/research/`, `docs/investigations/`, or `docs/adr/`.
