# Architecture Decision Records

ADRs record accepted decisions that should guide future work across issues or
PRs. They should be short, evidence-oriented, and updated by supersession rather
than silent rewrite.

## Index

- [ADR 0001: Durable documentation structure](0001-durable-documentation-structure.md)

## Format

Use this format for new records:

```md
# ADR NNNN: Title

Date: YYYY-MM-DD
Status: Accepted | Proposed | Superseded

## Context

## Decision

## Consequences
```
